## 📌 Sobre o projeto

Este repositório contém meu **Portfólio Web**, desenvolvido inicialmente como parte dos exercícios do módulo de Fundamentos do curso de Desenvolvimento Web da **Trybe**.

O objetivo é colocar em prática os conhecimentos adquiridos em HTML, Git e GitHub, criando uma página pessoal para apresentar minhas habilidades, experiências e interesses.

O projeto será atualizado progressivamente, acompanhando minha evolução nos estudos de desenvolvimento web.

## 👨‍💻 Sobre mim

Olá! Sou **Rodrigo Macedo Conceição**, brasileiro, residente em Juiz de Fora, Minas Gerais.

Tenho formação na área de Administração, experiência com empreendedorismo e gastronomia e atualmente estou em transição de carreira para a área de desenvolvimento de software.

Sou apaixonado por tecnologia, resolução de problemas e aprendizado contínuo. Busco desenvolver minhas habilidades técnicas e construir projetos que contribuam para meu crescimento profissional.

## 🚀 Tecnologias utilizadas

Neste estágio inicial, o projeto utiliza:

- **HTML5:** estruturação e organização do conteúdo.
- **Git:** controle de versão e acompanhamento das alterações.
- **GitHub:** hospedagem e gerenciamento do repositório.
- **VS Code:** ambiente de desenvolvimento.

Futuramente, pretendo incorporar CSS, JavaScript e outras tecnologias conforme avanço nos estudos.

## 📋 Funcionalidades

O portfólio apresenta:

## 🛠️ Como executar o projeto

**1. Clone o repositório:**

```bash
git clone git@github.com:macedorodrigo/portfolio-web.git
```

**2. Acesse o diretório:**

```bash
cd portfolio-web
```

**3. Abra no VS Code:**

```bash
code .
```

**4. Execute o projeto:**

Abra o arquivo `index.html` diretamente no navegador ou utilize a extensão **Live Server** do VS Code.
